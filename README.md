# Adaptive Federated Reinforcement Learning-Based Energy Consumption Optimization System

GitHub implementation of the proposed smart-building energy-management project.

The prototype contains:
- Local HVAC Q-learning agents
- Federated averaging of local Q-models
- Shared Energy Storage System (SESS) Q-learning
- Simulated weather, occupancy, PV and electricity price
- Comfort-aware rewards
- CSV results and an energy plot
- Optional ESP32 sensing/control firmware

The project presentation describes local HVAC learning, partial model-weight sharing,
global aggregation, and a second stage for battery charging/discharging. This code
implements those ideas as a software simulation. The ESP32 section is an optional
prototype; it is not a measured hardware experiment.

## Run

```bash
pip install -r requirements.txt
python main.py
```

Longer run:

```bash
python main.py --rounds 30 --episodes 20
```

Outputs:
- `results/simulation_history.csv`
- `results/energy_results.png`

## Architecture

```text
 Building 1 ─┐
 Building 2 ─┼─> Federated Aggregation ─> Global HVAC Model
 Building N ─┘
                         |
                  Predicted HVAC Load
                         |
                   Battery RL Agent
                         |
              Charge / Discharge / Idle
                         |
                  Grid + PV + SESS
```

## Privacy note

The simulation sends model tables to the federated server rather than raw room
observations. A production deployment should additionally use secure aggregation,
authentication, encryption and, where appropriate, differential privacy.

## Important

All numerical results generated by this repository are simulated. Do not present
them as physical hardware measurements without performing and documenting a real
hardware experiment.
